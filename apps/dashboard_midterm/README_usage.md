# 运行说明

## 1. 安装依赖

```bash
pip install -r requirements.txt
```

## 2. 启动应用

```bash
streamlit run app.py
```

## 3. 默认数据目录

代码中默认读取：

```python
DEFAULT_DATA_DIR = r"D:\GraduationProject\data\cleaned"
```

如果你的数据目录不同，可以在应用左侧边栏直接修改。

## 4. 当前实现的评论子图采样策略

为了避免一次性把所有评论都绘制成网络图，当前默认采用：

1. 优先选择“存在回复关系”的评论线程；
2. 在线程内部优先保留点赞高、回复多、互动强的评论；
3. 如果开启“优先高质量评论”，则先筛出高质量候选评论，再补齐必要的祖先链路；
4. 最终按 `max_nodes` 限制子图规模，保证 PyVis 在答辩展示时更稳定。

这套策略更适合老师现场查看“评论链条结构”和“重点评论用户画像”，而不是追求全量还原。
