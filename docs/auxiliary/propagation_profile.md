# 传播画像构建方法与流程

本文档概述项目中“传播画像”模块的方法设计、处理流程和输出含义。说明以 `scripts/weibo_analysis/propagation_profile/user_propagation_profile.py` 的当前实现为准，重点描述如何从用户微博、用户基础信息和被转发源作者信息中构建用户级传播特征。

## 任务目标

传播画像模块面向微博用户的历史发布与转发行为，目标是把分散的行为记录转化为稳定、可解释、可用于后续建模的用户级传播特征。与长期情绪画像侧重用户表达的情绪基线不同，传播画像更关注用户在信息扩散链路中的行为方式、信息来源偏好、互动表现和潜在影响力。

该模块在项目链路中承担用户传播属性补充的作用。上游清洗流程提供高质量用户微博和用户基础画像数据；本模块在用户级别聚合原创、转发、转发评论、来源账号类型和互动表现；下游的 Agent 构建、群体模拟或用户分层分析可以据此识别不同用户更可能承担的传播角色。

## 输入数据

流程默认读取三类 Parquet 数据。

第一类是清洗后的用户微博数据，主要提供微博编号、用户编号、原始正文、清洗后正文、文本质量、互动量、是否转发以及被转发微博编号。该表用于统计用户的原创与转发行为，也用于把转发记录连接回被转发的源微博。

第二类是高质量用户基础信息，主要提供用户编号、高质量微博数量、活跃天数、原创比例、粉丝数、认证状态和用户等级。该表决定本次画像覆盖的用户集合，并为活跃度、粉丝层级和影响力计算提供基础属性。

第三类是源作者信息，主要提供源作者编号、粉丝数、认证类型和用户等级。该表用于识别用户转发内容的来源类型，例如媒体、政府、机构、个人认证账号或高粉丝账号。

输入阶段会检查三类数据是否具备必要字段，并统一关键编号、计数、互动量和等级字段的数值格式。布尔字段也会被整理为稳定的真假值，以减少后续聚合时由缺失值或类型不一致带来的偏差。

## 用户集合与基础画像

传播画像以用户基础信息表中的用户为建模对象。流程会先确定这些用户编号，然后只在微博行为表中保留属于这些用户的记录。这样可以保证最终输出的用户数与基础信息表一致，即使某些用户在微博表中缺少可用记录，也仍会生成一条画像结果。

基础画像首先保留用户的高质量微博数量、活跃天数、原创比例、粉丝数、认证状态和用户等级。粉丝数会经过平滑处理后按分位数划分为低、中、高三个层级，用于表达用户账号规模的大致位置，而不是直接暴露极端粉丝数对判断的影响。

活跃度不只由发博数量决定，也会同时考虑活跃天数。流程会分别对高质量微博数量和活跃天数做归一化，再合成为传播活跃度分数，最后按分位数划分为低、中、高三个等级。这样可以区分短时间集中发布和长期持续活跃两类不同的行为模式。

## 原创与转发行为

模块会按用户统计微博总量、原创微博数量、转发微博数量和有效转发数量。有效转发要求转发记录中存在可用的被转发微博编号，避免把缺失、无效或占位编号误当作真实传播关系。

原创比例优先使用用户基础信息中已经计算好的结果。如果该字段缺失，则根据当前微博行为记录重新估计。转发比例由原创比例反推得到，并被限制在合理范围内。

转发评论比例用于衡量用户是否只是简单扩散，还是经常在转发时附加个人表达。流程会从转发正文中提取转发前的评论部分，并过滤掉低信息量文本。低信息量文本包括纯转发占位、纯话题、纯数字、纯符号、纯英文字母或单纯@用户等内容。只有文本质量较高且确实包含有效评论的转发，才会计入“转发时附加内容”的统计。

通过这一组指标，画像可以区分偏原创表达的用户、偏转发扩散的用户，以及在转发时常附加态度或补充说明的用户。

## 信息来源偏好

传播画像会进一步分析用户转发内容来自哪些类型的源账号。流程先把用户的有效转发记录与微博行为表中的源微博编号相连接，找到被转发微博的源作者；再把源作者与源作者信息表连接，补充认证类型、粉丝数和等级。

源作者认证类型会被归并为几类更适合传播分析的来源类型：媒体、政府、机构、个人认证、普通用户和未知。其中，企业、校园、网站、应用、团体或机构等类型会统一视作机构来源。

在成功连接源作者信息的转发记录中，模块按用户统计不同来源类型所占比例，包括媒体来源比例、政府来源比例、机构来源比例、个人认证来源比例、高粉丝来源比例，以及“高粉丝个人认证账号”来源比例。高粉丝来源以源作者粉丝数的上四分位作为相对阈值，因此它表达的是在当前数据集内部的高影响力来源，而不是一个固定的外部标准。

基于这些比例，流程构造两个综合分数。媒体依赖得分强调用户是否更常转发媒体、政府或机构账号，其中媒体权重最高，政府和机构次之。KOL 敏感得分强调用户是否更常转发高粉丝个人认证账号或其他高粉丝账号，其中高粉丝个人认证来源占更大权重。

这部分指标用于判断用户的信息输入更接近组织化信息源、个人意见领袖，还是没有明显的来源依赖。

## 互动表现与影响力

互动表现主要来自用户微博的互动量。流程会计算每个用户的平均互动量，并根据全体微博互动量的上四分位识别高互动微博，再统计用户高互动微博所占比例。平均互动量反映整体反馈水平，高互动微博比例则反映用户是否稳定产生相对更容易获得反馈的内容。

影响力得分由账号规模、互动表现、认证状态和用户等级共同构成。粉丝数和平均互动量会先经过平滑和归一化，以减少极端值影响；认证状态作为额外加分项；用户等级提供辅助性的账号成熟度信号。当前权重设计中，粉丝规模占比最高，其次是互动表现，再到认证状态和用户等级。

影响力得分会被限制在 0 到 1 之间，并按分位数划分为低、中、高三个等级。该指标不是对真实社会影响力的绝对估计，而是在当前数据集内部对用户潜在传播能力的相对刻画。

## 传播角色识别

在基础指标、来源偏好和影响力指标生成后，模块会为每个用户分配一个或多个传播角色。角色不是互斥类别，而是根据用户行为特征叠加得到的标签集合。

当用户传播活跃度较低时，会被标记为低活跃观察者；原创比例较高时，会被标记为原创表达者；转发比例较高时，会被标记为转发扩散者；转发评论比例较高时，会被标记为转发评论者。

当媒体依赖得分达到一定水平时，用户会被标记为媒体信息跟随者；当 KOL 敏感得分处于较高分位时，用户会被标记为 KOL 敏感型用户。若用户影响力得分处于高位，同时高互动微博比例也较高，则会被标记为潜在影响者。没有触发任何特定规则的用户会被归为普通参与者。

这种多标签设计可以表达微博用户传播行为的混合性。例如，一个用户既可能是转发扩散者，也可能是媒体信息跟随者；另一个用户则可能同时具备原创表达和潜在影响者特征。

## 中文摘要生成

除结构化指标和标签外，模块还会为每个用户生成一段中文传播摘要。摘要会综合五类信息：传播活跃度、原创或转发倾向、信息来源偏好、影响力水平和适合承担的传播角色。

表达倾向部分会区分明显偏原创表达、明显偏转发扩散、偏转发且常附加内容、转发时较常附加个人内容，以及原创与转发相对均衡等情况。

来源偏好部分会区分信息来源是否偏向媒体政府机构、是否偏向高影响力个人账号、是否两者兼具，或者是否没有明显来源依赖。

角色解释部分会把多标签结果转换为更易读的功能性描述，例如更适合作为信息扩散节点、原创表达型节点、转发并附加态度的扩散节点、潜在意见传播节点，或普通参与节点。这样生成的摘要便于人工审阅，也便于后续在 Agent 构建阶段快速理解用户的传播风格。

## 输出结果

最终输出是用户级传播画像表，默认保存到 `data/profile/weibos/propagation_profile/user_propagation_profile.parquet`。每个用户对应一行，主要包含以下几类字段。

第一类是基础规模与活跃度字段，包括用户编号、高质量微博数量、活跃天数、粉丝层级和传播活跃度等级。

第二类是表达与转发字段，包括原创比例、转发比例和转发评论比例，用于描述用户更偏向自主表达、简单扩散还是带评论转发。

第三类是来源偏好字段，包括媒体、政府、机构、个人认证、高粉丝账号和高粉丝个人认证账号的来源比例，以及媒体依赖得分和 KOL 敏感得分。

第四类是互动与影响力字段，包括平均互动量、高互动微博比例、影响力得分和影响力等级。

第五类是解释性字段，包括传播角色和传播摘要。它们把前面的数值指标转化为更适合阅读、筛选和下游使用的用户传播特征描述。

## 质量检查与运行反馈

结果生成后，流程会进行基础质量检查。首先，输出用户数必须与输入的用户基础信息表一致，确保没有用户在聚合过程中被意外丢失。其次，所有比例和得分字段都必须位于 0 到 1 之间，且不能为空。最后，粉丝层级、传播活跃度等级、影响力等级、传播角色和传播摘要等关键解释字段不能缺失或为空。

运行结束时，流程会打印若干检查信息，包括输入用户数、输出画像用户数、有效转发记录数、成功连接源微博的转发记录数、成功连接源作者信息的转发记录数，以及粉丝层级、传播活跃度等级、影响力等级和传播角色的分布情况。这些反馈可以帮助判断当前数据是否具有足够的转发关系覆盖，以及来源信息连接是否充分。

## 运行流程概述

完整流程可以概括为七个阶段。

第一，读取用户微博、用户基础信息和源作者信息三类输入数据，并检查必要字段。

第二，整理字段类型，统一用户编号、微博编号、转发微博编号、计数、互动量、粉丝数和认证状态。

第三，以用户基础信息表为画像用户集合，筛选对应微博行为记录，构建基础用户画像和粉丝层级。

第四，按用户聚合原创、转发、有效转发和转发评论行为，得到表达与扩散倾向。

第五，连接被转发微博和源作者信息，统计用户转发来源类型，构建媒体依赖和 KOL 敏感指标。

第六，聚合互动表现，结合粉丝规模、认证状态和用户等级计算影响力得分，并划分影响力等级。

第七，基于活跃度、表达倾向、来源偏好和影响力识别传播角色，生成中文摘要，完成质量检查并保存画像表。

整体来看，传播画像模块采用的是规则聚合与可解释评分相结合的方法。它不依赖额外模型训练，而是把清洗后的行为数据转化为一组含义清晰的用户级指标，使后续模拟系统能够更细致地区分不同用户在信息传播过程中的潜在功能。
