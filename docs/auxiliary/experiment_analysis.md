# 实验结果说明与分析

本文基于 `scope/data/outputs/simulation/multiround/20260521_150429_0cdb1d` 中的一次多轮模拟结果，对“武大回应图书馆事件”下的 Agent 参与、群体情绪演化、立场变化和互动网络结构进行说明。实验分析承接 `docs/auxiliary/experiment_design.md` 中的设定：本次实验不以预测真实舆情走势为目标，而是观察系统能否在高争议、高负向情绪的公共事件中稳定呈现用户参与、KOL 扩散、有限上下文影响、情绪传染与立场变化等现象。

## 单事件模拟实验结果

依据文件：`selected_event.json`、`config.json`、`dynamics_summary.json`。

本次运行使用事件 `event_5194986460286423`，话题为“武大回应图书馆事件”。事件输入中使用 184 条高质量评论，高质量评论比例为 0.95，主导情绪为 `disgust`，主导立场为 `against`，事件本身已具有明显的负向情绪和反对立场基础。模拟配置与实验设计保持一致：最多载入 30 个 Agent，运行 5 轮讨论，保留第 0 轮初始状态，启用 LLM 反应生成、互动机制和情绪立场动态机制，互动模式为 `kol_first`，每轮最多 5 个 KOL 优先发声，普通 Agent 最多接收 3 条上下文评论。

### 智能体样本概况

依据文件：`agent_initial_states.csv`、`agent_states_by_round.csv`、`config.json`。

本次实验实际载入 30 个 Agent，与配置中的 `max_agents = 30` 一致。样本在记忆用户层级上分布均衡，`core`、`normal` 和 `background` 各 10 个；认证类型以普通用户为主，共 26 个，另有 4 个个人认证用户。影响力等级中，高影响力 Agent 10 个，中影响力 14 个，低影响力 6 个，说明样本既包含能够优先发声和扩散的节点，也保留了较多普通观察者与跟随型用户。

从传播角色看，样本中“转发评论者”出现 17 次，“原创表达者”出现 15 次，“转发扩散者”出现 11 次，“低活跃观察者”出现 10 次，“KOL 敏感型用户”出现 6 次。这种结构比较适合 `kol_first` 互动模式：少数高影响力节点先形成话语刺激，随后由转发、评论和观察型用户在有限上下文中进行二次表达。

初始情绪分布为正向 8 个、中性 12 个、负向 10 个，平均情绪分数为 -0.0713，整体只略偏负向；初始立场分布则更集中，27 个 Agent 为中性，3 个为反对，平均立场分数为 -0.2181。也就是说，虽然事件输入本身高度负向、反对立场鲜明，但 Agent 初始状态并未直接复制评论区分布，而是保留了长期画像中的情绪差异和立场保守性。这为后续观察“事件刺激和互动上下文如何推动群体向负向和反对方向移动”提供了对照基础。

### 多轮模拟过程结果

依据文件：`round_metrics.csv`、`active_reactions.jsonl`、`interactions.csv`、`dynamics_summary.json`。

5 轮正式讨论中，系统共生成 98 条活跃反应，全部来自 LLM 生成且解析成功，没有出现回退或解析失败记录。反应类型中，评论 52 条，带评论转发 46 条，二者比例接近，说明讨论既包含直接表达，也包含扩散式表达。按发声类型看，KOL 优先发声共 25 条，正好对应 5 轮中每轮 5 个 KOL；普通 Agent 反应 73 条，说明 KOL 首发之后确实带动了普通用户参与。

逐轮参与率在 0.5667 到 0.7333 之间波动，未出现讨论中断。第 1 轮有 20 个 Agent 参与，第 2 轮 19 个，第 3 轮达到最高的 22 个，第 4 轮回落到 17 个，第 5 轮恢复到 20 个。这个过程说明事件刺激和 KOL 首发能够持续维持讨论热度，但普通 Agent 的参与仍会受到自身活跃度、上下文可见性和轮次状态影响。

### 典型智能体行为分析

依据文件：`agent_states_by_round.csv`、`active_reactions.jsonl`、`interactions.csv`。

典型 Agent 的轨迹能够展示不同画像如何在同一事件下产生差异化行为。`weibo_user_5539703320` 是最明显的高影响力核心节点，属于个人认证用户，传播角色为“原创表达者、潜在影响者”，影响力分数为 0.8945。该 Agent 在 5 轮中全部参与，累计作为源节点产生 129 条互动边，输出权重合计 81.48，是整个网络中最强的扩散源。它的情绪长期保持负向，最终情绪分数为 -0.6266；立场则从 -0.2739 进一步下降到 -0.5743，说明其主要作用不是被群体改变，而是持续输出强烈质疑和反对表达，推动其他节点接触负向上下文。

`weibo_user_7768467810` 则代表高频受影响的普通扩散节点。该 Agent 为核心层普通用户，传播角色为“转发扩散者、转发评论者”，自身影响力不高，但活跃度为 0.85，易于持续参与。它 5 轮均参与，5 轮均受到邻居影响，累计入边 15 条，输入权重合计 10.07。其情绪从 0.0000 下降到 -0.6555，立场从 -0.2420 下降到 -0.5688，最终由中性转为负向和反对。该个体体现了多轮上下文对普通活跃用户的累积影响：它不是主要话语源，却在反复接触高影响力评论后逐步完成情绪和立场转向。

`weibo_user_7782039772` 代表低活跃观察者被事件讨论逐步卷入的过程。该 Agent 初始情绪分数为 1.0000，是样本中明显正向的低影响力普通用户；它只在第 3 轮和第 5 轮参与，累计接收 6 条互动边。最终其情绪下降到 -0.1544，立场从 -0.2000 下降到 -0.3223，标签由正向中性转为中性反对。这个轨迹说明，低活跃用户即使参与轮次较少，也可能在高负向事件和重复上下文影响下出现明显情绪回落。

`weibo_user_3557512532` 展现了另一种更保守的变化。它是核心层普通用户，具有“KOL 敏感型用户”特征，初始情绪分数为 0.7637，第 1、2、5 轮参与，最终情绪下降到 -0.0697，但立场仍保持中性附近，最终立场为 -0.2115。其最后表达仍强调“到底真相是什么、希望调查给出清楚说法”。这说明系统中并非所有受影响 Agent 都会完全转向强反对立场；一部分用户会吸收负面氛围，但仍保留程序性观望和事实核查倾向。

## 群体情绪与立场演化分析

依据文件：`round_metrics.csv`、`dynamics_summary.json`。

整体来看，本次实验呈现出清晰的短周期舆论收敛过程：群体情绪从轻度负向持续下降为中度负向，群体立场从以中性为主转为以反对为主，互动网络则由少数高影响力节点向多数普通节点传播。最终动态汇总显示，平均情绪分数变化量为 -0.3892，平均立场分数变化量为 -0.2109，最终 24 个 Agent 为负向情绪，23 个 Agent 为反对立场，曾受邻居影响的 Agent 达到 26 个。

### 群体情绪变化分析

依据文件：`round_metrics.csv`、`dynamics_summary.json`、`active_reactions.jsonl`。

群体平均情绪从第 0 轮的 -0.0713 持续下降到第 5 轮的 -0.4605，说明讨论过程显著强化了负向情绪。负向情绪占比也从初始的 33.33% 上升到最终的 80.00%，而正向情绪占比从初始的 26.67% 下降到第 4 轮和第 5 轮的 0。这个变化与事件输入中的高负向评论分布、LLM 反应中大量 `disgust` 标签、以及 KOL 首轮高强度表达之间形成了相互印证。

情绪变化在前 3 轮最明显。第 1 轮平均情绪降至 -0.1862，第 2 轮降至 -0.2883，第 3 轮进一步降至 -0.3812，同时负向情绪占比从 40.00% 提升到 73.33%。第 4 轮和第 5 轮仍继续下降，但下降幅度变小，平均绝对情绪变化量从第 1 轮的 0.1536 逐步降至第 5 轮的 0.0690。这说明系统在前期完成了主要情绪转向，后期更多表现为负向状态的稳定和小幅加深。

情绪波动度从初始的 0.5598 持续下降到最终的 0.2129，说明 Agent 之间的情绪差异被逐轮压缩。结合典型个体轨迹可以看到，初始正向或中性的 Agent 在接触负向事件刺激和上下文评论后普遍向负向区域移动，而初始已经高度负向的 Agent 变化相对有限。这种“差异收缩”是本次情绪演化的核心特征：群体没有变得更加分散，而是围绕负向情绪形成了较高一致性。

### 群体立场变化分析

依据文件：`round_metrics.csv`、`dynamics_summary.json`、`agent_states_by_round.csv`。

群体平均立场从第 0 轮的 -0.2181 下降到第 5 轮的 -0.4290，整体向反对方向移动。初始阶段只有 3 个 Agent 被标记为反对，占比 10.00%；第 1 轮后反对立场占比快速升至 50.00%，第 2 轮为 63.33%，第 3 轮为 70.00%，第 4 轮达到 80.00%，最终第 5 轮稳定在 76.67%。全程没有出现支持立场 Agent，说明事件语境和生成反应共同限制了立场空间，主要分化发生在“反对”和“保持中性观望”之间。

与情绪演化相比，立场变化更体现为从中性向反对的逐步迁移。第 0 轮有 27 个中性立场 Agent，而最终仍有 7 个保持中性，说明立场并未完全一边倒。部分 Agent 虽然情绪下降明显，但仍在表达中保留“等待调查”“不要急着站队”等程序性判断，因此没有被更新为强反对。这一点使模拟结果更接近公共事件讨论中的真实分层：情绪氛围可以快速负向化，但立场表态仍受到个体画像、事实不确定性和表达风格约束。

立场波动度从初始的 0.0227 上升到最终的 0.1609，最终极化分数也为 0.1609。这个结果说明，群体平均立场虽然整体向反对收敛，但内部差异并未像情绪那样收缩，而是随着一部分 Agent 转入强反对、另一部分 Agent 维持中性观望而有所扩大。因此，本次实验中的立场演化不是简单的完全同质化，而是形成了“反对立场占主导、少数中性立场保留”的结构。

### 互动网络与关键节点分析

依据文件：`interactions.csv`、`network.graphml`、`round_metrics.csv`、`active_reactions.jsonl`。

本次运行共记录 219 条互动边，聚合后的 `network.graphml` 包含 30 个节点和 78 条有向边，说明所有 Agent 都进入了网络结构，但实际传播路径集中在部分源节点和多数目标节点之间。互动类型中，同轮上下文边 102 条，转发边 99 条，回复边 18 条，表明多数影响发生在“看到他人评论后表达”以及“带评论转发”的传播链条中，而不是狭义的一对一回复。

网络呈现明显的 KOL 驱动结构。互动边的唯一源节点只有 6 个，而目标节点达到 26 个，说明少数发声节点承担了大部分扩散功能。`weibo_user_5539703320` 是最核心的源节点，输出 129 条边，远高于其他节点；`weibo_user_5312381713` 输出 52 条边，`weibo_user_7895557083` 输出 24 条边，三者均为个人认证或潜在影响者，并且都在 5 轮中持续活跃。这种结构与 `kol_first` 模式一致：高影响力用户优先发声，随后普通用户在其评论基础上形成再表达。

从目标节点看，`weibo_user_7768467810`、`weibo_user_6741543022`、`weibo_user_6365892134` 等 Agent 的入边均达到 15 条，并且多轮持续受到邻居影响。这些节点本身不一定具备高影响力，却因为活跃度、易感性或转发评论角色而成为情绪和立场传递的主要承接者。最终它们大多转为负向和反对状态，说明网络中的关键目标节点对群体收敛也很重要：KOL 负责制造高权重刺激，普通活跃节点负责把刺激吸收并转化为持续参与。

互动强度也在后期增强。平均互动权重从第 1 轮的 0.3895 上升到第 5 轮的 0.5194，尽管第 4 轮参与人数下降，平均互动权重仍达到 0.5127。这说明后续轮次中的上下文选择更集中于高影响力或更相关的评论，互动数量并不是唯一影响因素；在讨论逐渐收敛后，较少但更强的上下文边仍能维持负向情绪和反对立场。综合来看，本次实验成功形成了“高影响力节点发起表达、普通活跃节点承接扩散、群体情绪和立场逐步偏移”的可解释传播链条。
