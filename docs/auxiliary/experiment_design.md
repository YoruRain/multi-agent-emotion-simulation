# 实验设计

本实验面向微博热点事件中的群体情绪与立场演化过程，使用项目中的多轮 Agent 仿真模块进行验证。实验不以预测真实舆情走势为目标，而是考察系统能否在一个具有明确公共争议、情绪强度和传播结构的事件上，稳定呈现用户参与、KOL 扩散、情绪传染和立场变化等关键现象。

实验流程以真实微博事件为外部刺激，选取一组由长期画像构建的微博用户 Agent，在多轮讨论中记录每个 Agent 的情绪分数、立场分数、参与行为、可见上下文和互动边。系统输出的逐轮状态、互动记录和汇总指标共同构成实验分析的数据基础。

## 实验事件选择

本实验选择的事件编号为 `event_5194986460286423`，对应话题为“武大回应图书馆事件”。事件摘要为：武汉大学图书馆事件中，男生因女生强势而被迫承认不当行为并愿以金钱赔偿，引发对其是否被冤枉的争议，校方已回应并启动调查复核。

选择该事件主要基于数据充分性、社会讨论热度、情绪立场鲜明性和 Agent 分化空间四个方面。

首先，该事件具有较好的评论数据基础。事件输入记录中使用了 184 条高质量评论，评论高质量比例为 0.95，能够为事件层面的情绪分布、立场分布和规范违背判断提供相对稳定的依据。相比评论量过少或评论质量不稳定的事件，该事件更适合作为多轮仿真的验证对象。

其次，该事件具有较高的真实热点属性。事件所属话题的热度点击量为 13709266，话题类型属于社会公共事件。高热度意味着该事件在真实平台环境中具备广泛讨论基础，也更符合毕业设计中对热点舆情模拟场景的设定。

再次，该事件的情绪和立场特征较为集中。事件记录显示，评论区负向情绪占比约为 0.8767，反对立场占比约为 0.8729，主导情绪为 disgust，主导立场为 against，规范违背程度为 high。这种高负向、高反对、高规范评价的事件结构，有利于观察负面情绪扩散、群体立场趋同和强情绪表达在多轮讨论中的变化。

最后，该事件具有较明显的 Agent 分化空间。围绕“是否被冤枉”“校方调查复核是否充分”“公共空间中的行为责任如何界定”等议题，不同用户可以形成多种讨论角色，例如强烈谴责者、制度责任追问者、程序正义关注者、理性观望者、情绪化转发者和 KOL 扩散者。相比纯娱乐类或单一哀悼类话题，该事件更容易体现社会公共事件中用户长期画像、事件刺激和互动影响共同作用下的群体情绪演化。

## 智能体与参数设置

实验中的 Agent 来自项目预先构建的微博用户画像输入。每个 Agent 由基础身份、长期情绪画像、主题兴趣画像、传播画像、历史记忆和系统提示词共同描述。其中，基础身份用于标识用户层级、认证状态和传播角色；长期情绪画像用于初始化情绪倾向；主题兴趣影响其是否容易参与公共议题；传播画像中的影响力、活跃度、媒体依赖度和 KOL 敏感度则参与发言选择、上下文选择和互动权重计算。

本次实验最多选取 30 个 Agent 参与模拟，并使用随机种子 42 保证抽样、参与决策和反应生成过程可复现。模拟轮数设为 5 轮，同时保留第 0 轮初始状态，因此最终状态记录覆盖第 0 轮到第 5 轮。若 30 个 Agent 均成功载入，`agent_states_by_round.csv` 将包含 180 条状态记录，不含表头。

实验启用 LLM 反应生成参数，使活跃 Agent 在每轮讨论中尽量生成符合其画像和事件语境的微博式反应。当 LLM 不可用或输出无法解析时，系统仍会回退到规则反应，以保证实验流程不中断。这样的设置兼顾了表达自然性和实验稳定性。

互动机制采用 `kol_first` 模式。每一轮中，系统先根据影响力、活跃度、传播角色、媒体依赖度和转发倾向选择最多 5 个高影响力 Agent 作为优先发声者；随后普通 Agent 会在观察已发声评论后决定是否参与。每个普通 Agent 最多接收 3 条上下文评论，并允许上一轮活跃评论进入可见上下文。该设置用于模拟真实微博讨论中“高影响力用户先发声，普通用户随后受到上下文影响”的传播过程。

实验同时启用情绪与立场动态机制。状态更新时，系统综合上一轮自身状态、邻居评论影响、事件刺激和本轮自身表达，对 Agent 的情绪分数与立场分数进行更新。情绪和立场分数均限制在 -1 到 1 的范围内，并使用边界阻尼避免分数过快达到极端值。该机制使实验能够观察多轮讨论中的情绪累积、立场收敛或波动，而不是只记录彼此独立的一次性发言。

本实验使用的主要运行设置如下。

| 参数类别 | 设置 | 实验含义 |
| --- | --- | --- |
| 事件输入 | `event_5194986460286423` | 使用“武大回应图书馆事件”作为公共热点刺激。 |
| Agent 规模 | 最多 30 个 Agent | 控制实验规模，便于人工检查状态演化和互动记录。 |
| 模拟轮数 | 5 轮，另含第 0 轮初始化 | 观察短周期群体讨论中的连续变化。 |
| 随机种子 | 42 | 保证抽样和参与决策可复现。 |
| 反应生成 | 启用 LLM，失败时回退规则生成 | 兼顾微博式表达质量和运行稳定性。 |
| 互动模式 | `kol_first` | 模拟高影响力用户优先发声、普通用户随后响应的讨论结构。 |
| KOL 发声上限 | 每轮最多 5 个 | 控制高影响力节点数量，避免少数用户完全主导实验。 |
| 上下文评论数 | 每个普通 Agent 最多 3 条 | 控制可见信息范围，形成有限注意力条件。 |
| 跨轮上下文 | 启用上一轮上下文 | 使前一轮讨论能够继续影响后一轮参与者。 |
| 情绪立场动态 | 启用 | 支持情绪传染、立场演化和邻居影响分析。 |

实验运行后，系统会在多轮模拟输出目录下生成本次运行结果。核心输出包括本次配置、选中事件、初始状态、逐轮 Agent 状态、逐轮群体指标、活跃反应记录、互动边记录、互动网络文件和动态汇总结果。这些输出分别用于检查实验配置、回溯事件背景、分析个体状态变化、观察群体指标趋势和展示互动网络结构。

## 评价指标设计

评价指标围绕“实验是否稳定完成”“群体情绪是否发生变化”“群体立场是否发生变化”“互动结构是否产生影响”四个层面展开。指标主要来自 `round_metrics.csv`、`agent_states_by_round.csv`、`interactions.csv` 和 `dynamics_summary.json`。

第一类是基础运行指标，用于判断实验是否按设计规模稳定完成。主要关注总 Agent 数、活跃 Agent 数、参与率和轮次数。总 Agent 数用于确认样本规模是否达到设定上限；活跃 Agent 数和参与率用于观察每轮讨论热度；轮次数用于确认输出是否覆盖第 0 轮初始化和 5 轮正式模拟。该类指标是后续分析的前提，如果 Agent 数量、轮次或参与率异常，需要先检查输入数据或运行配置。

第二类是情绪演化指标，用于刻画群体情绪状态及其变化。平均情绪分数反映整体情绪方向，负值越低表示群体情绪越偏负面；正向、中性和负向情绪占比用于描述群体情绪分布；情绪波动度用于衡量同一轮中 Agent 情绪差异；平均绝对情绪变化量和最大绝对情绪变化量用于观察一轮更新带来的情绪变动强度。对于本实验选择的高负向事件，重点关注负向情绪是否在多轮讨论中保持主导，以及 KOL 先发声和上下文传播是否会进一步放大负向倾向。

第三类是立场演化指标，用于分析群体观点方向和极化程度。平均立场分数反映整体支持或反对方向；支持、中性和反对立场占比用于描述立场分布；立场波动度和极化分数用于衡量群体内部立场差异；平均绝对立场变化量和最大绝对立场变化量用于判断多轮互动是否推动个体立场发生明显调整。由于该事件初始反对立场占比较高，实验分析中需要重点观察反对立场是否持续占优，以及普通 Agent 在接触高影响力评论后是否出现立场趋同。

第四类是互动影响指标，用于评价互动机制是否真正参与了状态更新。主要指标包括 KOL 发声数量、普通活跃 Agent 数量、互动边数量、平均互动权重、高影响力互动数量、获得上下文的 Agent 数量、平均上下文评论数、平均邻居数量、受邻居影响的 Agent 数量和平均邻居影响权重。这些指标可以说明讨论是否形成了有效的传播链条，也可以解释情绪或立场变化是否来自可见上下文与候选影响边，而不是仅由事件刺激或自身表达造成。

第五类是运行汇总指标，用于从整体层面对一次实验结果进行归纳。`dynamics_summary.json` 记录初始和最终平均情绪分数、初始和最终平均立场分数、情绪变化量、立场变化量、最终情绪分布、最终立场分布、最大情绪波动、最大立场波动、最终极化分数、总互动数和曾受邻居影响的 Agent 数量。这些指标适合放在实验结果小节中作为一次运行的总体结论。

综合上述指标，本实验的评价重点不是单一分数是否达到某个阈值，而是观察多轮讨论链路是否形成连贯的解释：真实热点事件提供强负向刺激，长期画像决定 Agent 的初始状态和参与倾向，KOL 优先发声形成可见上下文，普通 Agent 在有限上下文中生成反应，情绪与立场在邻居影响、事件刺激和自身表达共同作用下发生变化。只要这些指标能够在输出结果中形成相互印证，就说明系统具备对社会公共事件中群体情绪演化过程进行可解释模拟的能力。
