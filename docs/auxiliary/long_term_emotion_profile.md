# 长期情绪画像构建方法与流程

本文档概述项目中“长期情绪画像”模块的方法设计、处理流程和输出含义。说明以 `scripts/weibo_analysis/long_term_emotion_profile/` 目录下的当前实现为准，重点描述从用户历史微博到用户级情绪画像的转换过程。

## 任务目标

长期情绪画像模块面向用户历史微博文本，目标是把分散的微博表达转化为稳定、可解释、可聚合的用户级情绪特征。与单条文本情感分类不同，长期画像更关注用户在一段历史时期内的整体情绪倾向、表达强度、波动程度和可靠性。

该模块在项目链路中承担承上启下的作用：上游提供清洗后的用户微博数据和微调好的情绪分类模型；本模块先生成微博级情绪分析结果，再聚合为用户级长期画像；下游的 Agent 构建和群体情绪模拟可以据此获得用户的长期情绪基线。

## 输入数据

流程默认读取高质量用户微博数据。输入表需要包含用户编号、微博编号、微博正文、清洗后正文、年份、是否转发、文本质量等信息。其中，模型推理主要使用清洗后正文，结果展示和回溯仍保留原始微博正文。

在进入推理前，流程会进行基础筛选。默认情况下，只保留文本质量达到阈值的记录，并且只分析原创微博。这样做的目的是尽量让长期画像反映用户自身较稳定的表达习惯，而不是过多受到低质量文本、噪声内容或转发内容的影响。若研究任务需要，也可以把转发微博纳入分析，或关闭质量过滤。

## 微博级情绪推理

微博级推理使用已经微调好的 MacBERT 三分类情绪模型。模型将每条微博判断为积极、中性或消极，并给出三个类别的概率。流程不会重新训练模型，而是加载既有模型配置、分词器和分类权重，对用户历史微博进行批量推理。

推理完成后，每条微博会获得一组基础情绪指标：情绪标签、积极概率、中性概率、消极概率、模型置信度、极性得分和模型情绪强度。极性得分用于表示积极与消极之间的方向差异；模型情绪强度用于表示文本偏离中性的程度。一般来说，越接近中性的文本，模型情绪强度越低；积极或消极倾向越明显，强度越高。

为了支持长批量任务，流程支持断点续跑。若输出文件中已经存在部分微博的结果，下一次运行会跳过这些已完成微博，只处理剩余记录，并在保存时合并新旧结果。这样可以降低长时间推理中断后的重复计算成本。

## 规则情绪强度补充

模型概率能够反映文本整体情绪方向，但微博文本中还存在大量外显表达信号，例如连续问号、感叹号、重复字符、强语气词、情绪词和表情标记。模块会额外计算规则情绪强度，用于捕捉这些直接体现情绪外露程度的语言现象。

规则强度的定位不是重新判断情绪正负，而是补充“表达有多强”。例如，一条文本可能被模型判断为消极，同时又因为包含强烈语气词、哭泣表情或连续标点而被认为具有更高的外显情绪强度。相反，普通陈述性文本通常只会获得较低的规则强度。

最终的微博级情绪强度综合模型强度和规则强度。这样既保留深度模型对整体语义的判断，也引入微博平台常见表达方式带来的可解释增强。

## 文本权重设计

长期画像并不把每条微博都视为同等重要。模块会为每条微博计算文本权重，用于后续用户级聚合。权重主要考虑四类因素。

第一是文本长度。过短文本通常提供的长期画像信息较少，但如果短文本包含明显情绪词、表情、强标点或重复字符，仍会保留较高价值。

第二是内容来源。原创微博更能代表用户自身表达，因此权重高于转发微博。转发微博如果被纳入分析，也会被适度降权。

第三是模型置信度。模型越确信的判断，对长期画像的贡献越稳定；置信度较低的微博会降低聚合权重。

第四是画像价值。部分内容更像打卡、资料整理、链接分享、活动信息或泛化推荐，这类文本虽然可能有情绪标签，但对长期情绪画像的贡献有限，因此会被降权。若这类文本同时包含明确情绪表达，则不会被过度削弱。

通过加权机制，长期画像更偏向吸收高质量、表达明确、与用户自身情绪状态更相关的微博。

## 用户级聚合

微博级结果生成后，流程按用户编号进行聚合，形成用户级长期情绪画像。默认会生成两个画像版本：一个只使用特定年份微博，另一个使用全部历史微博。这样既可以观察用户在目标年份内的情绪表现，也可以保留跨年份的整体倾向。

聚合过程会统计每个用户可分析微博数量和加权微博数量，并基于文本权重计算积极、中性、消极三类情绪比例。平均极性、平均强度、强情绪比例、强积极比例和强消极比例也采用加权口径，以减少低价值文本和低置信度文本对结果的影响。

除加权指标外，流程还会保留极性中位数和极性标准差。中位数用于观察用户情绪方向的中心位置，标准差用于表示情绪表达的波动程度。若用户在不同微博中积极和消极表达交替明显，极性标准差通常会更高。

## 画像分类与摘要生成

用户级指标生成后，模块会进一步判断主导情绪、画像类型、画像可靠性，并生成中文摘要。

主导情绪由积极、中性、消极三类比例共同决定。当最高比例与第二高比例差距很小时，用户会被视为混合型表达，而不是强行归入单一情绪方向。

画像类型通过规则生成，主要考虑样本数量、中性比例、平均强度、积极或消极比例、强情绪比例、平均极性和波动程度。当前画像类型包括样本不足型、稳定中性型、强消极表达型、强积极表达型、高波动型、轻度积极型、轻度消极型和混合表达型。

画像可靠性主要由可分析微博数量决定。样本越多，画像越可靠；样本过少时，流程仍会输出结果，但会明确标记可靠性不足，并在摘要中提示仅供参考。

中文摘要会把整体情绪倾向、情绪强度、波动情况、强积极或强消极表达倾向以及可靠性说明组合成自然语言描述。该摘要便于在后续 Agent 构建、结果分析或人工检查中快速理解用户长期情绪特征。

## 输出结果

模块产生两类核心输出。

第一类是微博级情绪分析结果。它保留每条微博的用户编号、微博编号、正文、年份、是否转发、情绪标签、三类情绪概率、模型置信度、极性得分、模型强度、规则强度、综合情绪强度和文本权重。该结果既可用于检查模型推理质量，也可作为用户级聚合的直接输入。

第二类是用户级长期情绪画像。它以用户为单位，记录画像版本、可分析微博数量、加权微博数量、三类情绪比例、平均极性、中位极性、极性波动、平均情绪强度、强情绪比例、强积极比例、强消极比例、主导情绪、画像类型、可靠性和中文摘要。

默认情况下，微博级结果和用户级画像都保存为 Parquet 文件，便于后续统计分析和数据管道继续读取。微博级结果也支持 JSONL 输出，适合增量写入、人工抽查和断点续跑场景。

## 运行流程概述

完整流程可以概括为六个阶段。

第一，加载清洗后的用户微博数据，并根据文本质量、原创微博条件和运行参数筛选可分析样本。

第二，读取已有输出，识别已经完成情绪推理的微博，跳过重复记录。

第三，加载微调后的 MacBERT 情绪分类模型，对清洗后微博文本进行批量推理，得到三分类概率和情绪标签。

第四，结合原始微博信息、模型推理结果和规则强度特征，生成微博级情绪分析表，并计算每条微博在长期画像中的聚合权重。

第五，按用户编号和画像版本聚合微博级结果，计算用户长期情绪比例、极性、强度、波动和强情绪表达指标。

第六，根据聚合指标生成主导情绪、画像类型、可靠性等级和中文摘要，并保存用户级画像结果。

## 在整体项目中的作用

长期情绪画像是从真实微博数据到模拟 Agent 的关键中间层。它把用户历史表达中的情绪方向、表达强度和稳定性压缩为可计算特征，使后续 Agent 不只是基于单条评论或单次事件做反应，而是带有一定的长期情绪背景。

在单事件或多轮群体模拟中，长期情绪画像可以作为用户初始状态和行为倾向的重要依据。积极、消极、中性、强情绪、高波动或样本不足等差异，会影响 Agent 对事件刺激的反应方式、情绪强度和后续互动表现。

因此，该模块并不是单纯的情感分类后处理，而是一个面向社会媒体用户建模的画像构建流程：它将历史微博文本、模型判断、规则特征和加权聚合结合起来，形成既可解释又可用于后续仿真的长期情绪表示。
