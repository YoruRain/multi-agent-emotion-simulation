# 主题画像构建方法与流程

本文档概述项目中“主题画像”模块的方法设计、处理流程和输出含义。说明以 `scripts/weibo_analysis/subject_profile/` 目录下的当前实现为准，重点描述从用户历史微博到用户级主题画像的转换过程。

## 任务目标

主题画像模块面向核心用户的历史微博内容，目标是识别用户长期关注的话题方向，并将分散的微博级主题信号聚合为稳定、可解释的用户级特征。与单条微博主题识别不同，主题画像更关注用户在一段历史表达中的整体兴趣结构、公共议题参与程度、娱乐和日常内容偏好，以及主题信号在多大程度上来自用户自写文本或转发源微博。

该模块在项目链路中承担用户内容偏好建模的作用：上游提供清洗后的用户微博数据和高质量核心用户微博；本模块先生成微博级显式主题信号，再用隐式语义聚类补充显式信号缺失的微博，最后聚合为用户级主题画像；下游的用户记忆抽样、Agent 档案构建和群体情绪模拟可以据此获得用户的长期关注背景。

## 输入数据

流程主要使用两类微博数据。第一类是核心用户微博数据，包含核心用户发布的原创微博和转发微博，是主题画像的主分析对象。第二类是清洗后的用户微博总表，用于在处理转发微博时查找转发源微博，从而补充源微博正文和源微博话题标签。

输入数据中最重要的信息包括用户编号、微博编号、微博正文、文本质量、是否转发、转发源微博编号和微博话题标签。对于原创微博，主题信号主要来自用户自己的正文和话题标签；对于转发微博，流程会区分用户是否写了有效转发评论，并根据这一判断决定用户自写内容和转发源内容在主题识别中的作用。

## 显式主题信号构建

主题画像的第一步是生成微博级显式主题信号。显式信号主要来自三类来源：微博自身的话题标签、转发源微博的话题标签，以及正文中可以直接匹配到的主题关键词。

在处理原创微博时，流程直接使用用户微博正文和用户自带话题标签来识别主题。对于转发微博，流程会先判断该微博是否包含用户自己写的有效转发评论。如果转发评论具有可分析价值，主题匹配会同时参考用户评论和转发源微博；如果转发评论只是占位、纯符号、纯转发动作或文本质量较低，则主要使用转发源微博作为主题信号来源。

显式主题识别采用可解释的主题词典。词典覆盖社会公共事件、政策民生、时事政治、娱乐文化、日常生活、游戏动漫、情感表达、广告营销、媒体官方、体育竞技、数码科技等粗粒度类别。每条微博可以命中多个关键词，也可以被归入多个主题类别。这样的设计并不追求复杂的语义推断，而是优先保证主题来源清晰、便于人工检查，并能稳定支持后续聚合。

显式主题表还会为每条微博计算主题信号置信度。置信度综合考虑用户话题标签、转发源话题标签、关键词命中、主题类别命中和有效转发评论等加分因素，同时对低质量文本、空文本或缺少有效转发评论的转发微博进行降权。最终分数被限制在固定区间内，用于表示显式主题识别结果的可靠程度。

## 隐式主题聚类

仅依赖显式主题信号会遗漏一部分没有话题标签、没有明显关键词，但语义上仍有清晰主题的微博。为补充这类文本，模块引入隐式主题聚类。

隐式主题聚类的候选样本主要来自“原创、可分析、但显式主题类别缺失”的用户微博。这些文本先经过基础清理，去除空文本和过短文本，再使用中文语义向量模型生成文本表示。向量会进行归一化处理，使后续聚类更关注文本语义方向的相似性。

聚类阶段使用 MiniBatchKMeans，对多个候选簇数量进行实验。每组聚类结果都会保存微博所属簇编号、文本长度和样本到簇中心的距离，并输出簇规模、簇大小分布、聚类惯性和抽样轮廓系数等评估信息。该阶段的目的不是直接给出最终主题，而是为人工选择合适的簇数量和解释各簇语义提供依据。

## 聚类审阅与主题解释

为了让隐式聚类结果可解释，模块会为每个聚类结果生成审阅文件。审阅文件按簇整理样本，并分别提供靠近簇中心的代表文本、随机样本文本和远离簇中心的边缘文本。

这种审阅方式有两个作用。第一，靠近簇中心的样本有助于判断一个簇的核心语义；第二，随机样本和边缘样本可以帮助检查簇内部是否混杂、是否存在泛化过度或低密度表达。人工审阅后，项目为选定的聚类结果建立簇编号到细主题解释的映射，例如影视剧情评价、粉圈争议、旅行打卡、人生感悟、日常疲惫、性别议题、饮食健康等。

当前融合流程默认使用选定的二十簇聚类结果，并为每个簇配置细主题标签、粗粒度主题类别和簇级置信度。个别语义密度较低或难以稳定归类的簇会被标记为低置信度或“其他”，避免在用户画像中被过度解释。

## 显隐主题融合

微博级主题融合表将显式主题结果和隐式聚类结果合并到同一张表中。融合过程以显式主题表为主表，保证核心用户每条微博都保留在结果中；隐式聚类结果只作为补充信息，根据微博编号匹配回对应记录。

隐式主题并不是简单地直接采用聚类标签。流程会先根据人工配置的簇级置信度给出基础分，再结合每条微博到簇中心的距离进行调整。越靠近簇中心的文本越能代表该簇主题，置信度会相对更高；位于簇边缘或远离簇中心的文本则会被降权。只有当隐式主题具有明确类别、不是“其他”，且置信度达到阈值时，才会被视为有效隐式主题。

最终主题字段采用“显式优先、隐式补充”的融合规则。如果一条微博已经有显式主题类别，则最终主题直接采用显式结果，并保留显式置信度。如果显式主题为空但隐式主题有效，则使用隐式主题的粗粒度类别和细主题标签。如果隐式主题存在但置信度不足，流程会保留细主题标签用于检查，但不会把它计入最终主题类别。若两类信号都缺失，则该微博被标记为没有可用主题信号。

通过这一规则，融合表既保持显式信号的高可解释性，又扩大了主题覆盖范围，使更多原创表达能够进入用户级主题画像。

## 用户级主题画像聚合

微博级融合表生成后，流程按用户编号进行聚合，形成最终用户级主题画像。聚合指标既保留显式主题阶段的统计，也加入显隐融合后的最终主题统计。

在话题标签层面，画像会分别统计用户原创微博中的高频自写话题、转发微博中的高频源微博话题，以及两者合并后的高频话题。这些字段用于观察用户主动表达的兴趣与转发接触的信息源之间是否一致。

在主题类别层面，画像会统计显式主题类别、有效隐式细主题和最终融合主题分布。最终主题分布反映用户历史微博中各类主题出现的频率，是用户长期关注方向的核心表示。若一条微博包含多个主题类别，各类别都会计入分布，但占比的分母仍使用该用户的微博总数，便于衡量某类主题在用户历史表达中的覆盖程度。

聚合结果还会生成若干比例指标，包括公共议题主题占比、娱乐相关主题占比、日常生活主题占比、营销内容占比、显式主题覆盖率、有效隐式主题覆盖率和最终主题覆盖率。其中公共议题主要由社会公共事件、政策民生和时事政治等类别构成；娱乐相关主题包括娱乐文化、游戏动漫和体育竞技；日常生活还会吸收部分数码科技等生活化内容。

另一个重要指标是转发主题依赖度。它衡量用户画像中的主题信号在多大程度上依赖转发源微博，而不是用户自己的原创或转发评论。根据该比例，用户会被标记为自写主题主导型、转发源主题依赖型或混合主题来源型。这个标签有助于区分“用户主动关注什么”和“用户经常转发接触什么”。

## 画像可靠性与摘要

用户级主题画像会同时评估显式主题可靠性和最终主题可靠性。显式可靠性主要由用户微博数量和显式主题覆盖率决定；最终可靠性则进一步考虑显隐融合后的主题覆盖率和最终主题平均置信度。

当用户微博数量较多、最终主题覆盖率较高且平均置信度足够时，画像会被标记为高可靠。样本量或覆盖率处于中间水平时，画像被视为中可靠。若用户微博数量不足、可识别主题过少，或主题信号质量偏低，则画像被标记为低可靠。低可靠画像仍会保留结果，但在后续 Agent 建模中不宜过度依赖。

模块还会根据最终主题分布和隐式细主题生成中文主题摘要。摘要通常概括用户主要关注的粗粒度主题，并补充若干常见细主题。如果画像质量较低，摘要会明确提示可识别主题信号较少，只能粗略判断关注方向。

## 输出结果

主题画像模块产生四类主要输出。

第一类是微博级显式主题信号表，记录每条核心用户微博的用户话题、转发源话题、显式关键词、显式主题类别和显式信号置信度。该表用于检查规则主题识别质量，也是隐式候选筛选和后续融合的基础。

第二类是隐式主题聚类结果，包括文本向量缓存、不同簇数量下的聚类结果、簇评估统计和人工审阅文件。这些结果用于选择稳定的聚类配置，并为显式主题缺失的原创微博提供语义补充。

第三类是微博级主题融合表，保留显式主题字段、隐式聚类字段和最终融合主题字段。它是从微博级主题识别走向用户级聚合的直接输入。

第四类是最终用户级主题画像表。它以用户为单位，记录微博数量、原创和转发数量、高频话题、主题分布、公共议题占比、娱乐和日常主题占比、营销内容占比、主题来源依赖、主题覆盖率、平均置信度、可靠性标签和中文摘要。

默认情况下，主结果保存为 Parquet 文件，便于后续分析流程读取；部分融合结果还会额外生成 CSV 预览文件，方便人工抽查。

## 运行流程概述

完整流程可以概括为七个阶段。

第一，读取核心用户微博和用户微博总表，识别原创微博、转发微博、有效转发评论和转发源微博信息。

第二，基于用户话题标签、转发源话题标签和主题关键词词典，生成微博级显式主题信号和显式置信度。

第三，从显式主题缺失但仍可分析的原创微博中筛选隐式主题候选文本。

第四，使用中文文本向量模型生成候选微博的语义表示，并在多个簇数量下进行 MiniBatchKMeans 聚类实验。

第五，生成聚类审阅文件，结合代表样本、随机样本和边缘样本，为选定聚类结果建立人工主题解释。

第六，将显式主题表与隐式聚类结果合并，按显式优先、隐式补充的规则生成微博级主题融合表。

第七，按用户聚合微博级融合结果，生成最终主题分布、主题来源依赖、可靠性标签和中文摘要。

## 在整体项目中的作用

主题画像是从真实微博历史内容到模拟 Agent 的关键中间层。它把用户长期表达中的关注主题、信息来源和内容偏好压缩为可计算特征，使后续 Agent 不只是拥有情绪基线，也具有相对稳定的兴趣背景和议题偏好。

在用户记忆样本构建中，主题画像可以帮助挑选更能代表用户长期关注方向的微博。在 Agent 档案构建中，主题画像可以转化为用户长期兴趣、公共议题参与程度、娱乐或日常内容偏好等描述。在单事件或多轮群体模拟中，这些主题特征可以影响 Agent 对事件刺激的关注点、立场表达和互动倾向。

因此，该模块不是简单的关键词统计，而是一个结合显式规则、语义聚类、人工解释和用户级聚合的主题建模流程。它在可解释性和覆盖率之间取得平衡，为后续仿真提供稳定、可追溯的用户主题表示。
